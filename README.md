# 🛒 Genetic Shop — متجر إلكتروني بالخوارزمية الجينية (بدون قاعدة بيانات)

مشروع جامعي يعرض كيفية استخدام **الخوارزمية الجينية (Genetic Algorithm)** لاقتراح المنتجات على المستخدمين، مع قراءة البيانات **مباشرة من ملفات CSV / Excel** بدون أي قاعدة بيانات.

---

## ✨ المميزات

- 🎨 تصميم **Dark Modern** عصري بالـ CSS فقط
- 🧬 خوارزمية جينية كاملة (Tournament Selection + Order-1 Crossover + Mutation + Elitism)
- 📂 قراءة مباشرة من `data/*.csv` (أو xlsx بعد التحويل)
- ⚡ نظام **Cache ذكي** يتجدّد تلقائياً عند تعديل الملفات
- 👥 لوحة أدمن مع **اختبار حي للخوارزمية** ومخططات التقارب
- 🛒 سلة تسوق + ملف مستخدم + توصيات مخصصة

## 🧬 شرح الخوارزمية الجينية

ملف: `algorithms/genetic.php` — class `GeneticRecommender`

| المفهوم | التطبيق |
|---------|---------|
| **الكروموسوم** | مصفوفة من K معرّفات منتجات (بدون تكرار) |
| **الجين** | `product_id` |
| **اللياقة (Fitness)** | `1.5×CF + 1.2×Behavior + 0.6×Popularity + 0.8×Diversity` |
| **الاختيار** | Tournament Selection (k=3) |
| **التزاوج** | Order-1 Crossover (يضمن عدم تكرار المنتج) |
| **الطفرة** | استبدال جين عشوائي بمنتج جديد (10%) |
| **النخبوية** | الاحتفاظ بأفضل كروموسوم لكل جيل |

### مكوّنات اللياقة:

1. **CF (Collaborative Filtering):** متوسط تقييمات مستخدمين مشابهين (نفس البلد + فرق عمر ≤5).
2. **Behavior:** `views×1 + clicks×2 + purchases×3` (مع عقوبة على ما اشتراه فعلاً).
3. **Popularity:** `log(1 + عدد_التقييمات)` — تفضيل لطيف للشائع.
4. **Diversity:** عدد الفئات الفريدة في الـ K توصيات.

## 📊 كيف يقرأ النظام البيانات؟

عند أول طلب لأي صفحة:

```
طلب → DataStore::products()
       ↓
   هل /cache/abc123.cache موجود وأحدث من products.csv؟
       ├─ نعم → unserialize ← cache (سريع جداً ⚡)
       └─ لا  → اقرأ CSV → خزّن cache → ارجع البيانات
```

- **مرة واحدة في الجلسة:** البيانات في الذاكرة (`static array`).
- **بين الجلسات:** الكاش على القرص (يتجدد تلقائياً عند تعديل CSV).
- **مسح الكاش:** من لوحة الأدمن → "مسح الكاش".

## ✏️ تعديل البيانات

### الطريقة 1: عدّل CSV مباشرة
افتح `data/users.csv` بـ Excel، عدّل، احفظ → الموقع يلتقط التغيير تلقائياً.

### الطريقة 2: استخدم xlsx
1. ضع ملفاتك في `data/source/users.xlsx` ...
2. ```bash
   composer require phpoffice/phpspreadsheet
   php tools/convert_xlsx_to_csv.php
   ```
3. مسح الكاش من لوحة الأدمن.

## 📝 للتقرير الجامعي

اشرح في تقريرك:

1. **لماذا GA؟** التوصيات مشكلة بحث في فضاء ضخم (C(500,8) ≈ 7×10¹⁵ احتمال). GA يجد حلاً جيداً في ثوانٍ.
2. **التمثيل (Representation):** Permutation-based chromosome.
3. **مقارنة:** قارن مع توصية عشوائية أو Top-K بالشعبية فقط — ستجد GA يعطي **تنوعاً وتخصيصاً** أفضل.
4. **التقارب:** افتح `admin/ga_test.php` وخذ سكرين شوت لمنحنى التقارب.
